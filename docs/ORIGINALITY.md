# VOWMARK Clean-Room Originality Boundary

VOWMARK must remain independently recognizable. The public reference project was used to identify a broad opportunity around neutral judgment, not as a template for implementation or presentation.

## VOWMARK identity

VOWMARK is a public accountability register for self-issued, deadline-bound commitments backed by a bond and evaluated against frozen public evidence.

Its recognizable product language is:

- issuer
- commitment
- maturity
- evidence anchor
- review
- fulfilled
- breached
- inconclusive
- expired unresolved
- remedy address
- issuer record
- Maturity Board

## Do not copy or structurally reproduce

Do not copy from the reference repository or similar products:

- code;
- contract decomposition;
- method/function names;
- variable names;
- event schemas;
- prompts;
- storage schemas;
- README wording;
- project names;
- logos or icons;
- color systems;
- typography;
- page hierarchy;
- navigation structure;
- card layouts;
- forms;
- screenshots;
- animations;
- interaction order;
- dispute mechanics;
- buyer/seller roles;
- delivery/redelivery mechanics;
- clause-line mechanics;
- jury terminology;
- freelancer/deal framing;
- complaint/dispute bonds;
- seller payouts;
- reference frontend styling.

## Reusable high-level engineering principles

These generic principles are allowed because they are not product-specific copying:

- immutable/frozen terms;
- bounded evidence;
- independent validator retrieval;
- typed uncertainty;
- deterministic lifecycle legality;
- replay protection;
- prompt-injection resistance;
- canonical contract state;
- honest transaction finality;
- adversarial testing.

## Required hostile originality review before release

Before submission, compare the final project against the reference at the level of:

- product problem;
- roles;
- state machine;
- economic flow;
- contract boundaries;
- evidence model;
- vocabulary;
- routes;
- primary user journey;
- layout hierarchy;
- visual identity;
- transaction UX.

If a reviewer could reasonably describe VOWMARK as “the reference project with renamed nouns,” the build is not ready.
